A rig for every branch.

treerig gives every Git worktree its own environment: its own Compose stack, a routed local URL, a home directory and a lock. This book covers the name, the mark, colour, type and voice, so everything carries the same identity.

Name

treerig, typed trig

tree as in worktree, a checkout of a branch. rig as in a full working setup, the way people talk about a dev rig. Each worktree gets one.

Always lower case, treerig, the way it is typed. Capitalise it only to start a sentence. The command is trig; the full name is installed alongside it.

Files and settings carry the full name: treerig.toml, TREERIG_HOME, the dev.treerig label namespace.

Mark The Detached Fork

One path in, and your branch breaks away

It reads as a worktree does. main starts at a commit and runs on. At the split your branch leaves in red, with a clear break, because it lives in a space of its own.

  • The ring is a commit on main, where the path starts.
  • The ink path is main, running on to its next heading.
  • The red branch is yours: the worktree you’re in.
  • The gap is isolation. Your branch shares history with main but nothing else.

Small sizes

Below 20 px, use the 16 px file

At 16 px a scaled-down master blurs: the ring fills in and the gap closes. The 16 px file draws the same mark pixel by pixel, keeping the ring open and an empty pixel at the break.

Use treerig-favicon-16.svg at 16 px, and the master from 20 px up. The ring opens fully from 24 px.

Lockups

Mark, wordmark and icon

The wordmark is Archivo ExtraBold, semi-expanded, converted to outlines. The mark sits on the baseline to the left of it. Don’t re-set the wordmark in another face, and don’t place the mark to the right.

Colour

Evergreen, paper and one red

Evergreen and paper do nearly all the work. Signal Red is used sparingly and always means one thing: yours. If red appears anywhere else, it stops meaning that.

Voice

Plain, exact, and literal in the product

Write the way the README already does: say what happened, what is guaranteed and what to do next. The name may play on rigs; help text and errors never do.

DO
$ trig worktree remove This worktree is not registered; nothing to remove. $ trig up ✓ http://feature-login.acme.localhost
  • Use the product’s real nouns: worktree, lock, home, container.
  • Be specific about guarantees: “verified by ownership label, never by name.”
DON’T
$ trig worktree remove Whoops! Couldn’t find that rig 🌳 $ trig up Rigging up your tree… 🚀
  • No puns, jokes or emoji in output. It should read the same in a CI log.
  • Don’t apologise or guess; say what went wrong and how to fix it.
